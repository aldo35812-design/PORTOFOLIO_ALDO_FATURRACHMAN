# Portofolio Wuthering Waves — Aldo Faturrachman

Portofolio digital bertema **Wuthering Waves (Solaris-3 Expedition)** milik **Aldo Faturrachman** (Kelas 11 TKJ — SMKN 1 Blitar).

## Struktur Folder (Sudah Lengkap dengan Foto & Sertifikat)
- `index.html` — Halaman utama dengan cutscene pembukaan, layar loading, dan 7 bagian biodata lengkap.
- `style.css` — Gaya visual Obsidian & Resonance Gold khas Wuthering Waves.
- `script.js` — Animasi kanvas, transisi cutscene, pemutar audio latar (`30iNYa6Wl1o`), dan interaktivitas HUD.
- `assets/` — Seluruh foto profil, logo sekolah, dan sertifikat sudah tertanam otomatis di folder ini:
  - `foto-aldo.jpg` (Foto profil utama)
  - `logo-smk.png` (Logo SMKN 1 Blitar)
  - `logo-smp.png` (Logo SMP Negeri 1 Sutojayan)
  - `logo-sd.png` (Logo SD Negeri Kalipang 01)
  - `sertifikat-ujikom.jpg` (Sertifikat Kompetensi KKNI Level II TKJ)
  - `sertifikat-apis.jpg` (Sertifikat Pondok Ramadan 1446 H APIS)

## Cara Membuka di Visual Studio Code
1. Ekstrak file ZIP ini terlebih dahulu.
2. Buka **Visual Studio Code**, klik **File > Open Folder...**, lalu pilih folder `wuthering-life-journal`.
3. Klik kanan `index.html` > **Open with Live Server** (atau klik dua kali `index.html` untuk membukanya langsung di browser).
